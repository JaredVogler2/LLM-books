# StoryForge AI - Product Roadmap

## Phase 1: MVP (Current)

- [x] Core platform architecture
- [x] User authentication (JWT)
- [x] Child profile management
- [x] Book creation wizard (4-step)
- [x] Story generation engine (bedtime stories, ages 4-7)
- [x] Illustration generation (DALL-E 3, full color)
- [x] Character consistency system
- [x] PDF assembly (print-ready + digital)
- [x] Stripe payments (one-time purchase)
- [x] Printful integration
- [x] Email notifications (SendGrid)
- [x] Admin dashboard
- [x] SEO landing pages
- [ ] 24-page softcover only
- [ ] Single print partner (Printful)

## Phase 2: Expansion

- [ ] **Age range expansion**: 1-3, 8-10, 11-12
- [ ] **Story types**: Rhyming, Adventure, Educational/STEM
- [ ] **Choose Your Own Adventure**: Branching story paths
- [ ] **Coloring book mode**: Black & white line art output
- [ ] **All binding types**: Hardcover, spiral, saddle stitch
- [ ] **Paper options**: Premium matte, glossy
- [ ] **Book sizes**: 8.5x11 portrait, 11x8.5 landscape
- [ ] **Page counts**: 12 and 36 page options
- [ ] **Lulu integration**: Second print partner
- [ ] **Multiple copy discount**: Bulk pricing logic

## Phase 3: Subscriptions & Retention

- [ ] **Birthday subscription**: Annual auto-regeneration with age update
- [ ] **Holiday subscription**: Configurable calendar triggers (Christmas, Easter, etc.)
- [ ] **Quarterly series**: Same character, progressive story arc
- [ ] **Subscription management portal**: Pause, resume, update profile
- [ ] **Renewal reminder emails**: 30-day advance notice
- [ ] **Failed payment recovery**: Dunning email sequences

## Phase 4: Enhanced AI

- [ ] **Image-to-character pipeline**: Higher fidelity character extraction
- [ ] **Style transfer**: Multiple art styles (watercolor, digital, cartoon, etc.)
- [ ] **Character consistency v2**: LoRA fine-tuning per character
- [ ] **Audiobook generation**: Text-to-speech with character voices
- [ ] **Interactive preview**: Flip-through book preview before purchase
- [ ] **Story editing**: Allow parents to edit generated text before printing
- [ ] **Multi-language support**: Spanish, French, German, etc.

## Phase 5: Growth & Marketing

- [ ] **Referral program**: Give $5, get $5
- [ ] **Affiliate tracking**: UTM-based partner attribution
- [ ] **Abandoned cart recovery**: Email + retargeting sequences
- [ ] **Review system**: Post-delivery review request emails
- [ ] **Gift cards**: Purchasable gift codes
- [ ] **Programmatic landing pages**: Auto-generate niche pages from themes
- [ ] **Social sharing**: Share book previews on social media
- [ ] **Classroom/school bulk orders**: Teacher discount program

## Phase 6: Platform

- [ ] **API for partners**: White-label book generation
- [ ] **Mobile app**: React Native companion app
- [ ] **Book series editor**: Plan multi-book story arcs
- [ ] **Community gallery**: Showcase anonymized book covers
- [ ] **AI tutor integration**: Connect books to learning platforms
- [ ] **Analytics v2**: Cohort analysis, LTV prediction, churn prediction
